# 业务流程 21：秒杀商品通知订阅

## 一、设计思路

- 表结构、实体、DAO、控制器与后台页面由代码生成器产出，`sms_seckill_sku_notice` 保存会员、SKU、场次、订阅时间、发送时间与通知方式。
- 当前只有 CRUD，没有订阅/发送逻辑：没有用户订阅入口、没有取消订阅、没有短信或邮件发送、没有发送任务。
- `send_time` 是普通字段，只能由后台表单手工填写，不会在发送成功后回写。
- 订阅记录可以重复：表没有唯一键，同一会员、同一场次、同一 SKU 可以插入多条。
- 写入不做业务校验：会员、SKU、场次只按数字入库，不检查是否存在，也不校验通知方式取值。
- 列表分页不解析查询参数，`key` 不进入 SQL，查询框只影响前端展示。
- 后台菜单未进入仓库 SQL，页面需在运行库手动配置后才能从导航进入。
- 权限注解存在但未启用，接口没有实际的服务端鉴权。

## 二、主要功能描述

**触发与前置**

- 触发来源：管理员在 renren-fast 后台的秒杀商品通知订阅页面执行列表、新增、修改、删除。
- 请求以 `/gulimall/coupon/seckillskunotice/**` 进入网关，转发到 `gulimall-coupon`。
- 前置条件：`sms_seckill_sku_notice` 表已创建，后台菜单已在运行库配置。
- 控制器带 `@RequiresPermissions`，但 `gulimall.shiro.enabled` 未开启，注解不产生拦截。

**做什么**

- 列表：分页查询 `sms_seckill_sku_notice`，无过滤条件、无排序。
- 详情：按 id 查单条，供修改弹窗回显。
- 新增：请求体直接插入，字段按表单提交，`subcribe_time` 与 `send_time` 由前端文本传入。
- 修改：按主键覆盖字段，无乐观锁、无字段白名单。
- 删除：按 id 数组批量物理删除。

**不做什么**

- 当前只有 CRUD，没有订阅/发送逻辑。
- 不提供商城用户订阅、取消订阅的入口与接口。
- 不发送短信或邮件，没有相关依赖、服务或任务。
- 不校验会员、SKU、场次是否存在，不去重，不校验通知方式取值。
- 不记录发送状态、重试次数或失败原因，不自动写发送时间。

**结果**

- 列表返回全量分页，查询框无效。
- 新增和修改直接改变 `sms_seckill_sku_notice` 一行，重复数据同样插入成功。
- 删除为物理删除，不可追溯。
- 用户侧没有提醒能力，`send_time` 不随业务自动变化。

**数据变化**

- `sms_seckill_sku_notice`：列表与详情读取，新增插入，修改按主键更新，删除物理删除。
- Redis、MQ、短信与邮件：均不读写、不发送。
- `sys_menu`：后台动态路由读取菜单，仓库 SQL 中没有该页面记录。
- 会员联系方式：表和代码都没有手机号或邮箱，通知缺少必要的收件信息。

**异常与边界**

- `key` 搜索无效，后端始终返回全量分页。
- `subcribeTime` 或 `sendTime` 格式错误时反序列化失败，接口直接报错。
- `noticeType` 传入 0、1 之外的整数也能入库，后续发送无法路由。
- 会员、SKU、场次不存在时仍能插入，形成孤儿数据。
- 删除为物理删除，误删后无法恢复，也无法追溯历史。
- 权限注解不生效，能访问 coupon 服务即可执行 CRUD。
- 后台菜单缺失时页面无法从导航进入，只能手工配置运行库。
- 修改与新增只依赖前端表单的必填规则，后端没有字段级校验。

## 三、执行顺序

1. `seckillskunotice.vue#getDataList`：提交 `page`、`limit`、`key` 到 `/coupon/seckillskunotice/list`。
2. `SeckillSkuNoticeController#list`：接收请求参数，调用 `queryPage`。
3. `SeckillSkuNoticeServiceImpl#queryPage`：按分页查询 `sms_seckill_sku_notice`，`key` 不参与 SQL。
4. `SeckillSkuNoticeController#info`：按 id 调用 `getById`，结果放入 `seckillSkuNotice`。
5. `seckillskunotice-add-or-update.vue#init`：修改场景调 `info` 回填表单，新增场景准备空表单。
6. `seckillskunotice-add-or-update.vue#dataFormSubmit`：按 `id` 是否为空选择 `save` 或 `update`。
7. `SeckillSkuNoticeController#save`：调用 `save` 直接插入一行，无业务校验。
8. `SeckillSkuNoticeController#update`：调用 `updateById` 按主键覆盖字段。
9. `SeckillSkuNoticeEntity`：映射 `member_id`、`sku_id`、`session_id`、`subcribe_time`、`send_time`、`notice_type`。
10. `SeckillSkuNoticeDao#selectById` / `insert` / `updateById`：继承 `BaseMapper`，无自定义 SQL。
11. `SeckillSkuNoticeDao.xml#resultMap`：只做字段与属性映射，没有查询语句。
12. `seckillskunotice.vue#deleteHandle`：收集单条或批量 id，确认后提交到 `/delete`。
13. `SeckillSkuNoticeController#delete`：调用 `removeByIds` 按主键批量物理删除。
14. 用户侧无入口：秒杀页、商品详情页、会员中心均不调用订阅接口。
15. 发送侧无实现：没有定时任务、MQ 消息或发送服务读取该表。
