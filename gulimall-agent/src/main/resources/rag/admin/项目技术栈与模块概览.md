# 谷粒商城项目技术栈与模块概览

> 本文是**公开技术概览**，用于回答“这个项目用了什么技术、有哪些模块、怎么部署”这类问题。
> 不包含密钥、Token、内网 IP、数据库 SQL、服务器路径等敏感信息。

---

## 一、项目定位

谷粒商城是一套微服务电商系统，包含用户端商城和管理端后台：

- 用户端：商品浏览、搜索、购物车、下单、支付、订单、秒杀、优惠券、会员中心；
- 管理端：商品、订单、库存、营销、会员、AI 运营助手；
- AI 助手：`gulimall-agent` 独立微服务，提供多模型对话、只读查询工具、图片识别/生成和知识库问答。

## 四、部署概览

1. **Nginx** 作为统一入口，按域名区分用户端、管理端、搜索、秒杀、图片等站点；
2. **Spring Cloud Gateway** 负责把 `/gulimall/**` 请求路由到各微服务；
3. **Nacos** 提供服务注册发现和配置中心；
4. **MySQL / Redis / RabbitMQ / RocketMQ / Seata / Sentinel / Elasticsearch / MinIO / Milvus** 等中间件用 Docker 部署；
5. **Java 微服务**可以独立启动，按模块分配 JVM 堆内存；
6. **用户端**通过 Thymeleaf 页面和悬浮 AI 聊天窗访问；
7. **管理端**通过 Vue + Element UI 页面访问，AI 页面在 `admin` 站点的 `ai/chat` 路由；
8. **AI 助手**通过网关访问 `/gulimall/agent/**`，聊天流式接口使用 SSE。

## 五、AI 助手技术概览

- 多模型：DeepSeek、Qwen、GLM、Kimi、Claude、Gemini、GPT 等，通过统一模型目录和策略工厂创建；
- 对话：普通 JSON + SSE 流式，会话历史存 Redis，支持停止生成；
- 工具：商品、订单、会员、库存、秒杀、物流、天气、购物车等只读查询；
- 图片：上传看图（视觉模型）、生成图片（异步任务，完成后写回会话）；
- RAG：Milvus 向量库 + LangChain4J，按用户/管理员角色过滤公开/管理文档；
- 权限：用户端/管理端登录后由各自登录服务签发 `role=user` / `role=admin` 的 agent JWT，agent 只验签；工具按角色组装，用户只能查本人数据。
