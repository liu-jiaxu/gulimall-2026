# 谷粒商城使用指南

> 这份文档面向**使用者**：商城顾客和运营管理员。
> 不讲代码和部署，只讲“这个系统能做什么、每一步怎么操作”。

---

## 一、系统能做什么

谷粒商城分为两个使用端：

| 使用端 | 地址 | 适合谁 |
|---|---|---|
| 商城前台 | `http://gulimall.vip` | 购物顾客 |
| 管理后台 | `http://admin.gulimall.vip` | 运营、商品、订单、库存管理员 |

前台提供：注册登录、逛分类、搜索商品、看详情、加购物车、下单、支付、查订单、秒杀、领优惠券、个人中心、AI 购物助手。

后台提供：商品分类/品牌/属性管理、发布商品、库存采购、优惠券和秒杀活动、订单发货、会员管理、内容推荐、AI 运营助手。

> 如果浏览器打不开上面的地址，通常是本机还没有配置域名解析，请联系系统管理员处理。

## 二、商城前台

### 2.1 注册账号

1. 打开商城前台，点击右上角「注册」。
2. 填写用户名、手机号、密码。
3. 点击「获取验证码」，把收到的短信验证码填进去。
4. 勾选同意用户协议，点击「注册」。
5. 注册成功后回到登录页。

也支持第三方登录：

- GitHub 登录
- Gitee 登录
- 微信网页授权登录（开发测试环境使用微信测试号）

第三方登录第一次会自动创建一个商城账号，之后再用同一个第三方账号登录会进入同一个商城账号。

### 2.2 登录与退出

1. 点击右上角「登录」。
2. 输入用户名或手机号 + 密码。
3. 登录成功后右上角会显示昵称。
4. 需要退出时，点击昵称旁边的「退出」。

> 登录状态在商城各个页面之间共享：登录后去购物车、订单、个人中心都不需要重复登录。

### 2.3 首页与商品分类

首页会展示：

- 顶部分类导航；
- 轮播广告；
- 推荐商品；
- 秒杀活动入口。

点击左侧或顶部的分类，可以逐级进入二级、三级分类，查看该分类下的商品。

### 2.4 搜索商品

1. 在顶部搜索框输入关键词，例如「手机」「小米」。
2. 进入搜索结果页后，可以继续筛选：
   - 品牌；
   - 价格区间；
   - 是否有货；
   - 商品规格属性；
3. 可以按价格、销量、热度排序。
4. 点击商品卡片进入商品详情。

### 2.5 商品详情

商品详情页会展示：

- 商品图片；
- 商品名称、卖点；
- 可选的销售属性（颜色、内存、版本等）；
- 价格；
- 库存状态；
- 规格参数；
- 商品描述；
- 「加入购物车」「立即购买」按钮；
- 如果该商品正在参加秒杀，会显示秒杀入口。

选择完规格后，价格和库存会随所选 SKU 变化。

### 2.6 购物车

1. 在商品详情页选择规格后点击「加入购物车」。
2. 点击右上角购物车进入购物车页面。
3. 在购物车里可以：
   - 修改商品数量；
   - 勾选/取消勾选商品；
   - 删除单个商品；
   - 删除选中的商品；
   - 清除已经下架或无货的商品；
   - 查看已选商品数量和合计金额。
4. 确认无误后点击「去结算」。

> 未登录时也可以先把商品放进购物车；登录后系统会把游客购物车合并到你的账号购物车。

### 2.7 提交订单

1. 在结算页确认收货地址。
2. 没有地址时点击「新增收货地址」，填写收货人、手机号、省市区、详细地址。
3. 确认商品清单、数量、价格。
4. 选择优惠券、积分抵扣（如果有）。
5. 查看运费。
6. 点击「提交订单」。

提交成功后进入支付页。**订单提交后 30 分钟内未支付会自动取消，并释放库存。**

### 2.8 支付订单

1. 在支付页选择支付宝。
2. 跳转到支付宝沙箱收银台完成付款。
3. 支付成功后回到商城，订单状态会变成「待发货」。
4. 如果支付过程中关闭了页面，可以到「我的订单」里找到待付款订单继续支付。

> 当前使用支付宝沙箱环境，不会产生真实扣款。

### 2.9 我的订单

进入「我的订单」后，可以按状态筛选：

| 状态 | 含义 |
|---|---|
| 待付款 | 订单已提交，还没支付 |
| 待发货 | 已支付，等待仓库发货 |
| 待收货 | 已发货，等待你确认收货 |
| 已完成 | 已确认收货，交易完成 |
| 已关闭 | 超时未支付或主动取消 |
| 待退货 | 退款/退货申请处理中 |
| 已退货 | 退货完成 |

可以进行的操作：

- 查看订单详情；
- 取消未支付订单；
- 继续支付待付款订单；
- 查看物流公司和运单号；
- 确认收货；
- 申请退款/退货。

### 2.10 秒杀活动

1. 从首页秒杀入口或秒杀页面进入。
2. 选择秒杀场次。
3. 场次开始前可以查看商品和秒杀价。
4. 场次开始后点击「立即抢购」。
5. 抢购成功后进入确认页，提交秒杀订单。
6. 在订单列表里查看秒杀订单状态。

秒杀商品数量有限，抢完即止；同一场次同一商品通常每人限购。

### 2.11 优惠券与积分

- 优惠券：在个人中心或活动页领取，下单时满足门槛即可抵扣。
- 积分：购物、评价等行为可能获得积分，下单时可按规则抵扣。
- 成长值：用于会员等级成长。

### 2.12 个人中心

个人中心可以：

- 修改昵称、头像、性别、生日等资料；
- 修改密码；
- 管理收货地址（新增、修改、删除、设为默认）；
- 查看积分、成长值；
- 查看优惠券；
- 查看订单。

### 2.13 AI 购物助手

商城每个页面右下角都有一个可拖动的动漫宠物，点击她可以打开 AI 聊天窗。

**能问什么：**

- 商品推荐、分类、品牌、价格、库存；
- 购物车内容；
- 自己的订单状态、订单详情；
- 优惠券、积分、秒杀活动；
- 天气、地址位置；
- 商城的使用流程（例如“怎么下单”“怎么退款”）。

**不能问什么：**

- 技术开发、部署、密钥、数据库等与购物无关的问题；
- 别人的订单、地址等隐私数据；
- 管理端数据（用户端助手没有这些权限）。

> **模型能力提示**：不同模型擅长的方向不同。GPT-6.1 系列适合通用对话和看图，但通过当前 closeai 接口**不支持调用查库工具**；需要查订单、库存、购物车等实时数据时，请选择 DeepSeek、Qwen、GLM、Kimi、Claude 或 Gemini。系统默认已选择 DeepSeek，日常使用直接用默认模型即可。

**聊天窗功能：**

1. **拖动宠物**：按住宠物拖到任意位置，下次打开会记住位置。
2. **切换模型**：聊天窗顶部可以选择不同的 AI 模型。
3. **流式输出**：打开「流式」后，回答会逐字显示；关闭后等全部生成完再显示。
4. **新建对话**：点「＋」开始一个新对话；如果上一轮还在生成，会先自动停止。
5. **最近 10 轮**：聊天区默认显示当前对话最近 10 轮。
6. **历史对话**：点「🕘」查看最近 3 天的所有对话，可以切换或删除。
7. **搜索 3 天历史**：在历史面板输入关键词，可以搜索最近 3 天全部对话。
8. **搜索当前对话**：点聊天窗顶部的「🔍」，在当前对话里按关键词过滤。
9. **上传图片**：点输入框左侧的图片按钮，或者直接 `Ctrl+V` 粘贴截图，AI 会先识别图片再回答。
10. **生成图片**：直接说“帮我画一张促销海报”，AI 会调用图片生成能力并把图片显示在聊天里。
11. **自定义提示词**：在设置里填写你希望的回答风格，例如“回答简短一点，多用列表”。
12. **窗口颜色**：在设置里更换聊天窗主题色。
13. **自定义模型**：在设置里填写自己的模型名称、地址和密钥，保存后可以在模型下拉框里选择。
14. **停止生成**：回答过程中点输入框右侧的「■ 停止」，可以立即结束当前回答；新建或切换对话也会先停止上一轮。

> AI 只有登录后才能使用。未登录时点击宠物会提示先登录。

## 三、管理后台

### 3.1 登录后台

1. 打开 `http://admin.gulimall.vip`。
2. 输入管理员账号、密码、验证码。
3. 登录后进入后台首页。

### 3.2 系统管理

系统管理包含：

- 管理员列表：新增管理员、分配角色、重置密码；
- 角色管理：创建角色、给角色分配菜单权限；
- 菜单管理：维护后台左侧菜单；
- 定时任务：查看和管理定时任务；
- SQL 监控：查看数据库执行情况（仅管理员）。

### 3.3 商品管理

商品管理是后台最核心的部分，分为：

**分类维护**

- 新增一级、二级、三级分类；
- 修改分类名称、图标、排序；
- 删除没有子分类、没有被商品使用的分类。

**品牌管理**

- 新增品牌名称、品牌 logo、描述；
- 修改品牌信息；
- 删除品牌前要确认没有商品在使用。

**平台属性**

- 属性分组：把同一类属性放在一组，例如“屏幕”“CPU”“内存”；
- 规格参数：商品的通用参数，例如屏幕尺寸、电池容量；
- 销售属性：用户下单时要选择的规格，例如颜色、内存、版本。

**商品维护**

- SPU 管理：查看已创建的商品 SPU；
- 发布商品：从分类、品牌、属性一路填写，生成 SPU 和多个 SKU；
- 商品管理：查看 SKU、上下架、修改价格和库存。

### 3.4 库存系统

- 仓库维护：新增仓库、填写仓库名称和地址；
- 商品库存：查看每个 SKU 在每个仓库的库存、锁定库存；
- 采购单：创建采购需求、生成采购单、入库；
- 库存工作单：查看下单锁定库存、解锁库存的记录。

### 3.5 优惠营销

- 优惠券管理：创建满减券、折扣券，设置门槛、有效期、发行量；
- 发放记录：查看优惠券领取和使用记录；
- 专题活动：配置首页专题；
- 秒杀活动：创建秒杀场次、把 SKU 加入场次、设置秒杀价和限购；
- 每日秒杀：维护每天的秒杀场次时间；
- 积分维护：配置积分规则；
- 满减折扣：配置满减、打折活动；
- 会员价格：给不同会员等级配置专属价格。

### 3.6 订单系统

- 订单查询：按订单号、会员、状态、时间筛选订单；
- 订单详情：查看商品、金额、收货信息、支付信息；
- 发货：填写物流公司、运单号；
- 退货单处理：审核用户的退款/退货申请；
- 支付流水：查看支付记录；
- 退款流水：查看退款记录；
- 等级规则：配置订单相关的等级规则。

### 3.7 用户系统

- 会员列表：查看会员基本信息、等级、积分、成长值；
- 会员等级：维护等级名称、所需成长值、权益；
- 积分变化：查看会员积分增减记录；
- 统计信息：查看会员消费统计。

### 3.8 内容管理

- 首页推荐：配置首页推荐位；
- 分类热门：配置分类下的热门商品；
- 评论管理：查看和管理商品评论。

### 3.9 AI 运营助手

后台左侧「AI 助手 → AI 聊天」进入运营助手。

和用户端不同，运营助手可以查询：

- 全部订单、订单状态、订单明细；
- 交易额、订单数、商品销量、每日趋势；
- 商品、分类、品牌、SPU、SKU；
- 各仓库库存；
- 会员概要（手机号和地址会自动打码）；
- 优惠券、秒杀场次。

运营助手**只做查询**，不会修改商品、订单、库存，也不会执行发货或退款。

> 模型下拉框里如果标注「不支持查库」，说明该模型只能做通用对话/看图，不能查订单和库存；查运营数据请选默认的 DeepSeek 或其它支持工具调用的模型。

使用方式和用户端类似：可以切换模型、开关流式、查看 3 天历史、搜索对话、上传图片（也支持 `Ctrl+V` 粘贴截图）、生成图片、自定义提示词和自定义模型；生成过程中可以点「停止」结束当前回答。

## 四、关键流程详解

### 4.1 管理员上架一件真实 SKU

这是后台最常做的完整流程，按顺序操作：

**第 1 步：建分类**

1. 进入「商品系统 → 分类维护」。
2. 新增一级分类，例如「手机数码」。
3. 在一级分类下新增二级分类，例如「手机通讯」。
4. 在二级分类下新增三级分类，例如「智能手机」。
5. 记住这个三级分类，发布商品时要选它。

**第 2 步：建品牌**

1. 进入「商品系统 → 品牌管理」。
2. 新增品牌，例如「小米」。
3. 上传品牌 logo。
4. 保存。

**第 3 步：建属性**

1. 进入「商品系统 → 平台属性 → 属性分组」。
2. 给三级分类新增属性分组，例如「屏幕」「性能」「外观」。
3. 进入「规格参数」，给每个分组添加参数，例如：
   - 屏幕：屏幕尺寸、分辨率、刷新率；
   - 性能：CPU 型号、运行内存、存储容量；
   - 外观：颜色、重量。
4. 进入「销售属性」，添加用户下单时要选的属性，例如「颜色」「内存」。

> 规格参数用于展示商品详情；销售属性用于生成不同的 SKU。

**第 4 步：发布商品**

1. 进入「商品系统 → 商品维护 → 发布商品」。
2. 选择刚才建好的三级分类。
3. 选择品牌。
4. 填写 SPU 名称、卖点、描述。
5. 上传商品图片。
6. 填写规格参数。
7. 添加销售属性组合，系统会生成对应的 SKU。
8. 给每个 SKU 填写：
   - SKU 名称；
   - 价格；
   - 重量；
   - 默认图片；
   - 库存（也可以发布后到库存系统入库）。
9. 点击「保存」或「上架」。

**第 5 步：确认上架**

1. 进入「商品维护 → 商品管理」，确认 SKU 已经上架。
2. 进入「库存系统 → 商品库存」，确认该 SKU 有可用库存。
3. 打开商城前台，用分类或搜索找到这件商品，确认图片、价格、规格都正确。

**常见失败原因：**

| 现象 | 常见原因 |
|---|---|
| 发布商品时选不到分类 | 分类没建到三级，或者分类被禁用 |
| 选不到品牌 | 品牌没建，或者品牌没有关联到该分类 |
| 商品详情没有规格参数 | 规格参数没有绑定到属性分组/分类 |
| 下单时没有可选规格 | 销售属性没有配置，或者没有生成 SKU |
| 前台搜不到商品 | 商品没上架，或者搜索索引还没同步 |
| 下单提示库存不足 | 库存系统里该 SKU 的可用库存为 0 |

### 4.2 用户购买一件商品

1. 打开商城，登录账号。
2. 通过分类或搜索找到商品。
3. 进入商品详情，选择颜色、内存等规格。
4. 点击「加入购物车」。
5. 打开购物车，确认数量和勾选状态。
6. 点击「去结算」。
7. 选择收货地址；没有地址就先新增。
8. 选择优惠券、积分抵扣。
9. 确认运费和应付金额。
10. 点击「提交订单」。
11. 在支付页完成支付宝付款。
12. 回到「我的订单」，订单状态变成「待发货」。
13. 商家发货后，订单变成「待收货」，可以看到物流公司和运单号。
14. 收到货后点击「确认收货」，订单变成「已完成」。

### 4.3 秒杀一件商品

**管理员：**

1. 进入「优惠营销 → 每日秒杀」，创建秒杀场次（开始时间、结束时间）。
2. 进入「秒杀活动」，把商品 SKU 加入场次。
3. 设置秒杀价、限购数量、秒杀库存。
4. 保存并确认场次状态。

**用户：**

1. 在秒杀页选择场次。
2. 场次开始后点击「立即抢购」。
3. 抢购成功后进入确认页。
4. 提交秒杀订单。
5. 在订单列表查看秒杀订单。
6. 未支付同样会在超时后取消并释放秒杀库存。

### 4.4 退款/退货

1. 用户在「我的订单」里找到已支付订单。
2. 点击「申请退款/退货」，填写原因。
3. 管理员进入「订单系统 → 退货单处理」。
4. 审核通过或拒绝。
5. 审核通过后按流程退款。
6. 用户在订单里看到退款/退货状态。

### 4.5 使用 AI 助手查数据

**用户端：**

1. 登录商城。
2. 点击右下角宠物。
3. 直接问，例如：
   - “推荐一款 3000 元左右的手机”
   - “这个商品还有货吗？”
   - “我的订单到哪了？”
   - “帮我画一张 618 促销海报”

**管理端：**

1. 登录后台。
2. 进入「AI 助手 → AI 聊天」。
3. 直接问，例如：
   - “今天交易额是多少？”
   - “查一下订单号 2026... 的状态”
   - “某个 SKU 现在总库存多少？”
   - “最近 7 天销量最好的商品”

### 4.6 使用 AI 自定义模型

1. 打开 AI 聊天窗 → 设置。
2. 在「添加自定义模型」里填写：
   - 显示名称；
   - modelName；
   - baseUrl（必须是 https 地址）；
   - apiKey；或者勾选「使用公共 closeai key」；
   - 是否支持图片识别。
3. 点击「添加模型」。
4. 回到聊天窗顶部模型下拉框，选择刚添加的模型。
5. 不需要时可以在设置里删除。

> 自定义模型的 apiKey 会加密保存，页面上只显示掩码；但请不要在公共电脑上保存自己的私人密钥。

## 五、常见问题

### 登录相关

**Q：注册收不到短信验证码？**
A：开发环境短信服务可能没有配置，联系管理员查看验证码；正式环境检查手机号是否正确、短信余额是否充足。

**Q：登录后换一个页面又变成未登录？**
A：确认访问的是同一个主域名下的页面（例如都在 `gulimall.vip` 或它的子域名下）；清理浏览器缓存后重试。

**Q：第三方登录失败？**
A：确认第三方平台的回调地址配置正确；开发环境微信测试号仅用于调试。

### 购物相关

**Q：加入购物车提示无货？**
A：该 SKU 当前库存为 0，或者商品已下架；可以换一个规格。

**Q：提交订单提示价格变动？**
A：从加入购物车到提交订单期间商品价格发生了变化，刷新确认页后重新提交。

**Q：订单超时关闭了还能恢复吗？**
A：不能，超时关闭会释放库存，需要重新下单。

**Q：支付成功但订单还是待付款？**
A：支付回调可能有延迟，稍等刷新；如果长时间不变，联系管理员核对支付流水。

### 秒杀相关

**Q：秒杀按钮一直点不动？**
A：场次还没开始，或者已经结束；也可以刷新页面看最新场次。

**Q：秒杀成功但订单没生成？**
A：系统会异步建单，稍等后在订单列表刷新；如果长时间没有，联系管理员。

### AI 助手相关

**Q：点击宠物提示请先登录？**
A：AI 助手只对登录用户开放，先登录商城。

**Q：AI 回答“只能回答商城相关问题”？**
A：这是权限限制。用户端只能问购物/商品/自己的订单等；管理端可以问运营数据。

**Q：AI 说没有配置天气服务？**
A：管理员还没有配置天气接口的密钥，联系管理员。

**Q：上传图片失败？**
A：确认图片是 JPG/PNG/WebP，且不超过 8MB。

**Q：AI 生成图片失败？**
A：图片生成服务可能未配置或超时，稍后重试；也可以在设置里换一个模型。

**Q：历史对话找不到了？**
A：聊天记录只保留最近 3 天，过期会自动清理。

## 六、名词解释

| 名词 | 大白话解释 |
|---|---|
| SPU | 一款商品，例如“小米 15”；它是一组规格的统称 |
| SKU | 一款商品的具体规格，例如“小米 15 黑色 256G”；下单买的是 SKU |
| 分类 | 商品的归类，例如 手机数码 → 手机通讯 → 智能手机 |
| 品牌 | 商品的品牌，例如 小米、华为 |
| 规格参数 | 商品详情里展示的参数，例如屏幕尺寸、电池容量 |
| 销售属性 | 下单时要选的规格，例如颜色、内存 |
| 场次 | 秒杀活动的时间段，例如 10:00、14:00、20:00 |
| 优惠券 | 满足门槛后可以抵扣的券 |
| 库存锁定 | 下单时先把库存占住，防止别人买走；超时未支付会释放 |
| 预扣库存 | 下单前先在缓存里扣一次，减少数据库压力；最终以数据库库存为准 |
| 退款 | 订单支付后把钱退给用户 |
| 退货 | 用户把商品寄回商家后再退款 |
